### Installation
- To create the Python module with wrapped C++ code: 
	- Use the Project in the c++ folder
	- Install OpenNI2 from [OpenNI2](https://structure.io/openni/?srsltid=AfmBOopxqKcIPaKikYaKtega0IkYstv0SPbppemkyJ2OQprldQCDl6Ha) anywhere on your machine.
	- Change the *include_directories()* and *link_directories()* in the MakeLists.txt file to the new installation locations
	- Run the program
